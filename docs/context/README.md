# Weft JSON-LD context

Canonical namespace: `https://w3id.org/weft-network/ns#`

Context document: `https://w3id.org/weft-network/ns`

[`weft.jsonld`](weft.jsonld) is the pinned copy. Nodes must load this file at
startup and must not fetch remote contexts. The w3id redirect is registered
before federation is enabled; see
[`../adr/ADR-014-jsonld-namespace.md`](../adr/ADR-014-jsonld-namespace.md).

Do not rename or remove terms. Add terms and publish a new context version when
the namespace must change.
