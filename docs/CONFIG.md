# Weft — configuration

Status: design for the standalone MVP. Keys are illustrative until the loader and
`weft init` exist; update this file with the implementation.

Configuration is TOML. Environment variables override file values with the
`WEFT__SECTION__KEY` convention (double underscore between nesting levels):

```bash
WEFT__SERVER__BIND=0.0.0.0:8080
WEFT__DATABASE__URL=postgres://weft:secret@db/weft
WEFT__UPLOAD__MODE=review
```

Secrets should come from the environment or a secret file, never from a
world-readable `config.toml`.

## 1. Reference

```toml
# ── Node identity ─────────────────────────────────────────────────────────────
[node]
# Stable public origin. Must match the reverse proxy and TLS certificate.
public_url = "https://gifs.example"
# Human-readable name and optional description.
name = "Example GIF node"
description = "A small community node"
# Optional contact URL or address shown to operators, never in federation
# metadata unless explicitly intended.
contact = ""
# Node key file, generated by `weft init`. Root-readable only.
key_file = "/var/lib/weft/node.key"
# ActivityPub actor URL. Defaults to `${public_url}/actor`.
actor_url = "https://gifs.example/actor"

# ── Server ────────────────────────────────────────────────────────────────────
[server]
bind = "127.0.0.1:8080"
# Public origin behind the reverse proxy; used for absolute URLs.
external_url = "https://gifs.example"
# Request body limit for JSON (uploads use their own limit).
max_json_bytes = 1048576
request_timeout_seconds = 30
# Trust X-Forwarded-For only from these proxies. Empty = trust none.
trusted_proxies = ["127.0.0.1/32", "::1/128"]

# ── Database ──────────────────────────────────────────────────────────────────
[database]
url = "postgres://weft:weft@127.0.0.1:5432/weft"
max_connections = 10
connect_timeout_seconds = 5

# ── Storage ───────────────────────────────────────────────────────────────────
[storage]
backend = "local"                 # local | s3
path = "/var/lib/weft"
max_size = "10GB"                 # total blob + thumbnail budget
max_file_size = "15MB"            # per original upload
thumbnail_size = 512              # px, longest edge
# S3/MinIO when backend = "s3"
# endpoint = "http://127.0.0.1:9000"
# bucket = "weft"
# region = "us-east-1"
# access_key = ""
# secret_key = ""
# allow_path_style = true

# ── Upload policy ─────────────────────────────────────────────────────────────
[upload]
mode = "review"                   # open | review | closed
allowed_mimes = ["image/gif", "image/png", "image/jpeg", "image/webp"]
max_pixels = 16000000
max_frames = 300
max_decoded_memory = "256MB"
decode_timeout_seconds = 10
max_title_chars = 200
max_description_chars = 2000
max_tags = 20
max_tag_chars = 40
# Per-client token bucket; the client is a salted hash, not an IP.
rate_limit_per_hour = 20
rate_limit_burst = 5
# Optional proof of work for anonymous uploads.
proof_of_work = false

# ── Bandwidth and transfers ───────────────────────────────────────────────────
[bandwidth]
upload_limit = "20Mbps"
download_limit = "50Mbps"
max_concurrent_transfers = 4

# ── Replication (Phase 3) ─────────────────────────────────────────────────────
[replication]
enabled = false
automatic = false
max_replica_bytes = "5GB"
max_replicas_per_content = 5
eviction = "lru"                  # lru | lfu | manual
cache_ttl_days = 30

# ── Federation (Phase 2) ──────────────────────────────────────────────────────
[federation]
enabled = false
bootstrap_nodes = []
require_http_signatures = true
allow = []
block = []
max_inbox_bytes = 262144
clock_skew_seconds = 300
replay_cache_ttl_seconds = 3600
deliver_to_followers = true

# ── Moderation and licensing ──────────────────────────────────────────────────
[moderation]
default_licence_status = "unverified"
accepted_licences = ["CC0-1.0", "CC-BY-4.0", "CC-BY-SA-4.0"]
# Optional local/community blocklist files or URLs. Never mandatory.
blocklists = []
# Refuse content whose licence is missing when true.
require_licence = false

# ── Search ────────────────────────────────────────────────────────────────────
[search]
backend = "postgres"              # postgres | meilisearch (future)
# meilisearch_url = "http://127.0.0.1:7700"
# meilisearch_key = ""

# ── Observability ─────────────────────────────────────────────────────────────
[metrics]
enabled = true
bind = "127.0.0.1:9090"           # or expose /metrics on the main server

[logging]
level = "info"                    # error | warn | info | debug | trace
format = "json"                   # json | pretty
# Never log request bodies, media bytes, tokens or raw client addresses.

[privacy]
# Salt for rate-limit and report contact hashes. Rotate periodically.
hash_salt_file = "/var/lib/weft/hash.salt"
# Retention for hashed abuse records. 0 disables persistence.
client_hash_retention_days = 7
report_retention_days = 90

# ── HTTP limits ───────────────────────────────────────────────────────────────
[limits]
max_requests_per_minute = 120
max_media_requests_per_minute = 600
max_manifest_requests_per_minute = 300
```

## 2. Defaults and rationale

| Key | Default | Why |
|---|---|---|
| `upload.mode` | `review` | Anonymous open uploads are too risky for a new public node |
| `storage.max_file_size` | 15 MB | Covers most GIFs without enabling abuse |
| `upload.max_frames` | 300 | Bounds decode work |
| `upload.max_decoded_memory` | 256 MB | Keeps small nodes alive |
| `federation.enabled` | false | The MVP is standalone |
| `replication.enabled` | false | Opt-in by design |
| `search.backend` | `postgres` | No extra service for a small node |
| `privacy.client_hash_retention_days` | 7 | Enough for abuse handling, short enough for privacy |

The `weft init` command writes a minimal config with these values and a generated
key. It must refuse to overwrite an existing key without an explicit flag.

## 3. Validation rules

At startup:

- `public_url` and `external_url` are HTTPS origins with no path/query.
- `storage.path` is writable and has at least `max_file_size` free.
- `max_file_size` ≤ `storage.max_size`.
- `max_decoded_memory` is within the operator's budget and above the largest
  allowed image.
- `database.url` parses and connects; migrations are current.
- `federation.enabled` requires a key and an actor URL.
- `replication.enabled` requires `storage.max_size` > `max_replica_bytes` or an
  explicit acknowledgement.
- Blocklist entries parse and are HTTPS URLs or local paths.
- No secret is logged at startup.

## 4. Permissions

- Config file: `0640`, owned by the service user and group.
- Key file and hash salt: `0600`, owned by the service user.
- Storage directory: `0750`, owned by the service user.
- The database user needs only DML and DDL on the `weft` schema (DDL only for
  migrations).

## 5. Environment-only values

Always environment-only:

- `database.url` when it contains a password;
- S3 credentials;
- admin bearer token hash or secret;
- Meilisearch key;
- any future provider API keys.

Do not commit a real config with secrets. Use `.env.example` for names only.

## 6. Open points

- Exact size units and parser (`10GB` vs `10GiB`).
- Whether metrics use a separate listener by default.
- Default `upload.mode` for a node that is not publicly reachable.
- Proof-of-work parameters if enabled.
- Whether `require_licence` should be true for public nodes.
